Lucent Amigo Oculto

Sorteie o amigo oculto da família pelo WhatsApp. Cada pessoa recebe o próprio link e só vê quem ela tirou.

Esta página não está aberta num endereço da internet (por exemplo, foi aberta como arquivo ou numa pré-visualização), então daqui não dá para mandar links. Dá para fazer o sorteio com todos juntos: cada pessoa toca no próprio nome e vê quem tirou neste aparelho, uma de cada vez. Para mandar links pelo WhatsApp, abra o endereço publicado, como amigo-oculto.pages.dev.

2 · Quem participa

exemplo: troque pelos nomes da sua família
  • Celular ou e-mail (opcional): para mandar o link direto para a pessoa, pelo WhatsApp ou por e-mail. Fica só neste aparelho.
  • Ajudante: o número de quem abre o link junto com a pessoa (por exemplo, 3 para a Ana ajudar os avós). A pessoa ajudada não tira o próprio ajudante.
  • Colunas 1, 2, 3…: marque quem é do mesmo casal ou da mesma família. Quem estiver marcado na mesma coluna nunca tira o outro. Uma pessoa pode estar em mais de uma coluna.

Deslize a tabela para o lado para ver todas as colunas e o botão de remover.

3 · Sortear

O sorteio acontece neste celular ou computador. Ninguém, nem você, vê os pares na tela.

4 · Cada pessoa vê quem tirou

Como cada pessoa vai ver?

Atualizar muda só o necessário: quem entrou ganha um amigo, e uma ou duas pessoas ganham um amigo novo, marcadas abaixo. Os outros continuam iguais. Atenção: ao mandar os links novos, você vai poder deduzir quem tirou quem nessa troca.

Refazer o sorteio

Os links já enviados continuam abrindo o sorteio antigo, que aparece com a data e a hora dele. Avise o grupo para usar só os links novos.
